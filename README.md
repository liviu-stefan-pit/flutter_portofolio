# flutter_portofolio

Separate Flutter samples. Each folder is its own app. Run one with `flutter pub get` and `flutter run` inside that folder.

| Folder | What it is |
|---|---|
| `basic_layout` | Layout widgets. |
| `first_web_page` | A first Flutter web page. |
| `flutter_cheats` | Short cheat-sheet snippets. |
| `state_management` | State-management sample. |
| `learning_provider` | Provider practice. |
| `navigation` | Navigation sample. |
| `scrolling_experience` | Scrolling and lists. |
| `starter_app` | Default starter kept as a reference. |
| `todo` | Todo list with filters and search (Provider / Riverpod-style). |
| `google_books_api` | Early Google Books search sample. |
| `share_lib` | Later Google Books search app, with a repository and provider layout. Brought in from the old share_lib repository. |
